## භාවිත කරන හැටි

හැම සාරාංශයකම ඇත්තේ:
- **මූලික වචන**: ඒ කොටසට අදාළ කෙටි ශබ්දකෝෂයක්.
- **මූලික ඉගැන්වීම්**: සූත්‍ර කියන දේ, පොතේ උපමා, එක් පේළියක සාරයක් සමඟ.
- **බහුලව වන වැරදි වැටහීම්**: වැරදි සහ නිවැරදි කිරීම් වගුවක්.
- **ස්වයං පරීක්ෂණ ප්‍රශ්න**, පිළිතුරු ක්ලික් කළ විට පෙනෙන සේ සඟවා.
- **එක් පිටුවේ සාරාංශයක්** සහ **ප්‍රායෝගික අභ්‍යාසයක්**.

යෝජිත රටාව: එක් සාරාංශයක් කියවා, සතියක් එහි අභ්‍යාසය කර, ඉක්බිති පොතේ අදාළ දේශනා කියවන්න.

> **සටහන:** මේ සාරාංශ ඉදිරිපත් කරන්නේ කතුවරයාගේ අර්ථකථනයයි. ඇතැම් තැන්වල (භව තුනේ විග්‍රහය, *නාම* යන්නේ අර්ථය, අන්තරාභවය) එය සම්මත ථේරවාද අටුවාවලින් වෙනස් වේ. උපුටා දක්වා ඇති සූත්‍ර ඔබම කියවා විනිශ්චය කරන්න.
